## マージ後の確認とタグ

1. mainのBuild and test / Deployが成功したことを確認する。
2. check-publication-live.mjsへmainのマージcommitを渡し、公開evidence、19HTML、資産とPDFを照合する。
3. 公開トップ、各章、モバイル目次、PDFダウンロードを確認し、実行URLとcommitを本Issueへ記録する。
4. 人による承認と公開成功を確認後、そのmain commitへv0.2.0タグを付ける。別commitや未承認ブランチには付けない。
5. #15と残る原稿受入#11の条件を確認してクローズする。#22は開いたまま維持する。

## 不具合と差し戻し

受入失敗時にはタグとIssueクローズを行わず原因を修正します。公開後の不具合はrevert PRで戻し、mainの公開を確認します。
実機用説明書の発行・安全性能・規格適合の判断には未検証情報が残ります。架空PoCの出版受入をその承認として扱いません。
