# 付録E 用語集・索引

## E.1 用語集
| 用語 | 意味 | 関連章 |
|---|---|---|
| 意図する使用 | 製造者が定める目的と条件に従った使用 | 1、2、3 |
| 予見可能な誤使用 | 予想可能な人の行動に起因する意図外の使用 | 2 |
| 残留リスク | 保護方策を実施した後に残るリスク | 2 |
| 危険源 | 危害を生じる潜在的な原因 | 2 |
| ガード | 人が危険区域へ近づくのを妨げる物理的な保護方策 | 2、3 |
| インターロック | ガード等の状態と機械動作を関連付ける機能 | 2、3、9 |
| エネルギー隔離 | 有害なエネルギーの供給・蓄積・再投入を管理する措置 | 2、9、12 |
| ワーク | 装置で搬送・検査する樹脂製部品 | 1、3、7 |
| レシピ | 品種別の運転・判定設定の組合せ | 6、8 |
| 非常停止 | 緊急時に危険な動作を停止させる機能 | 2、7 |
| 点検 | 状態や機能が所定基準を満たすか確かめる行為 | 7、9 |
| 試運転 | 据付・設定後に動作や安全機能を確認する工程 | 5、6 |
