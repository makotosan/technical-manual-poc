# 第1章 はじめに

## 1.1 本書の目的

本書は、卓上型自動搬送・検査装置TM-100の輸送、据付、運転、保守、撤去までに必要な取扱情報を記載しています。装置の基本構成、危険源と残留リスク、据付・運転・段取り替え・保守・故障対応に関する説明を同一の原稿体系で管理します。

## 1.2 本書の適用範囲

| 項目 | 適用内容 |
|---|---|
| 機種 | TM-100 |
| 使用目的 | 樹脂製ワークのコンベヤ搬送、光電検出、簡易合否判定 |
| 設置条件 | 乾燥した屋内の作業台上 |
| 電源 | AC 100 V、50/60 Hz |
| 装置構成 | 搬送ユニット、検出ユニット、排出ユニット、制御ユニット、保護ガード |
| 対象としない用途 | 人員搬送、食品衛生用途、危険場所、可燃性・爆発性雰囲気、医療用途 |

仕様値と安全関連性能については、適用する装置の仕様書および検査記録と照合してください。

## 1.3 対象読者と必要な力量

| 役割 | 担当するライフサイクル | 必要な力量 |
|---|---|---|
| 設備管理責任者 | 導入、運用管理、使用停止 | 作業分担、安全管理、教育管理 |
| 運搬担当者 | 梱包、輸送、開梱、保管 | 荷扱い・重量物作業に関する教育 |
| 据付技術者 | 据付、接続、試運転 | 機械据付と電気安全の知識 |
| オペレーター | 運転、停止、品種切替、通常清掃 | 運転教育、異常時の停止判断 |
| 保守技術者 | 点検、調整、交換、修理 | 機械・電気の保守技能と作業許可 |

オペレーターはガード内の危険領域にアクセスする保守作業や電気配線の改造を行いません。異常により安全機能が疑われる場合は装置を停止し、設備管理責任者に連絡します。

## 1.4 作業前に確認すること

1. 自分が担当する作業と必要な力量・権限を確認する。
2. 第2章「安全上の注意」と当該作業章の警告を読む。
3. 機械の型式と仕様銘板が本書の対象と一致することを確認する。
4. 外観、電源配線、ガード、非常停止装置に異常がないことを確認する。
5. 不明な点、記載と実物の相違、安全装置の不具合がある場合は作業しない。

## 1.5 文書の構成と参照方法

第2章は全作業に共通する安全事項を扱います。第3章は機械の構成と用途を説明し、第4～6章は運用開始まで、第7～11章は日常運転と維持管理、第12章は使用終了に関する事項を扱います。付録では仕様・記録用紙・警告表示・交換部品・用語を参照できます。

安全情報は共通事項を第2章に示し、特定の作業に関わる警告は当該手順の近くにも記載する方針です。危険源の概念配置は[図2-1（第2章）](02-safety.md)を、機械構成は[図3-1～図3-4（第3章）](03-machine-overview.md)を参照してください。Web版では目次から章や節に移動し、PDF版では目次・ページ番号から該当箇所を探せる構成を目指します。

## 1.6 用語および略語

| 用語 | 本書における意味 |
|---|---|
| ワーク | 検査対象の樹脂部品 |
| 搬送方向 | 供給側から排出側へのコンベヤ移動方向 |
| 自動運転 | 作業者が危険領域に入らず搬送・検出・排出を繰り返す運転 |
| 段取り替え | ワーク寸法に応じたガイド・検出条件等の変更 |
| 安全状態 | 意図しない動作や危険エネルギーによる危害を防止するために必要な状態 |
| インターロック | ガードの状態と機械の動作を関連付ける保護機能 |
| 残留リスク | 保護方策を講じた後に残るリスク |
| LOTO | エネルギー遮断、施錠、表示等による意図しない再通電・再起動防止の管理方法 |

LOTOの具体的な手順、遮断点、検証方法は実機設計と設備側の手順に基づいて確定する必要があります。

## 1.7 関連文書

本書はISO 20607:2019／JIS B 9719:2022に示される取扱説明書の構成を参考にしています。関連概念としてISO 12100（リスクアセスメントとリスク低減）、ISO 7010（登録安全標識）、IEC 60204-1（機械の電気装置）等を扱います。適合性は各要求事項に対する設計・検証の記録によって判断してください。

## 1.8 文書の更新と保管

管理責任者は最新版の文書番号と版数を確認し、旧版と混同しないように管理することを想定します。設備改造、工程変更、危険源の追加、使用部品変更があった場合、取扱説明書の見直しが必要です。変更後の取扱説明書を現場へ配布する前に、記載と装置状態の整合を確認してください。
