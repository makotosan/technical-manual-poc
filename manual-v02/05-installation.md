# 第5章 据付・組立・試運転

## 5.1 対象と作業許可
本章は据付技術者と設備管理責任者が対象です。電気接続は適切な資格と権限を有する技術者に限ります。設備質量、外形、重心、保護接地、電源定格の最終値は未確定であり、作業開始前の設計ゲートとします。

## 5.2 据付条件
| 項目 | 要求条件／判定方法 |
|---|---|
| 作業台 | 本体・ワーク・作業荷重に対する強度を確認（数値仕様書参照） |
| 床面・作業台水平度 | メーカー確定公差内（仕様書参照） |
| 固定 | 指定取付位置・ボルト仕様（仕様書参照） |
| 作業・保守空間 | 図3-3の仕様書参照寸法確定後に確認 |
| 周囲環境 | 乾燥した屋内、結露や危険雰囲気がない |
| 電源 | 単相AC100V、50/60Hzは構想値。実機表示と照合 |
| 接地 | 設計された保護接地方法を電気担当者が検証 |

## 5.3 危険情報
> **警告 W-06／H-05：据付中の落下**  
> 持上げ点や荷重を確認しない据付は落下事故につながります。設計確定と運搬計画の承認なしに装置を持ち上げないでください。

> **危険 D-01／H-03：通電部への接触**  
> 電気的隔離および無電圧確認を行わずに電気系を接続すると致命的な感電のおそれがあります。資格と権限を有する担当者が、適用法規と電気設計資料に従って作業してください。

> **注意 C-01／H-08：不適切な固定**  
> 本体の移動や転倒を避けるため、指定した据付固定部と台の耐荷重を検証してください。

## 5.4 据付作業の流れ
1. 搬入・受入記録を確認し、未処理の損傷・欠品がないことを確かめる。
2. 据付図面と施工計画を承認する。寸法、重心、固定具が仕様書参照の場合はここで作業を停止する。
3. 作業場所、台の耐荷重、保守スペースと立入管理を確認する。
4. 指定された方法で装置を移動・配置する。
5. 水平と固定状態を測定・記録する。
6. ガードG01/G02、S01/S02、プッシャA01、制御盤EC01の損傷や脱落がないか確認する。
7. 電気担当者が電源・接地・保護機器を設計書に従って確認する。
8. 結線・保護装置確認記録を承認し、試運転段階へ移る。

## 5.5 安全システムの始業前点検

毎日の始業前に、教育を受け点検を許可された担当者が次の3項目を全て点検してください。初回据付・移設・修理後にも運転へ引き渡す前に同じ機能を確認してください。その他の設置時安全試験は5.6と承認済み検査基準で確認します。

### 5.5.1 点検前の準備

1. ワークを除き、無負荷で点検できる状態にしてください。
2. ベルト、プッシャ、開口部、ガード内に人・工具・異物がないことを確認してください。
3. 点検担当者と操作位置を定め、他者の起動操作と危険領域への立入りを防いでください。
4. ガード外から操作・観察できる承認済み点検方法を使用してください。カバーを開く試験でも内部へ手・身体を入れないでください。
5. エリアセンサーの試験片、試験位置、停止確認方法と合否判定条件の承認を確認してください。未確定又は安全に試験できない場合は、点検と通常運転を開始せずサービス窓口へ確認してください。

### 5.5.2 点検項目と合格条件

| 点検ID・対象 | 確認方法 | 合格条件 | 頻度 |
| --- | --- | --- | --- |
| SC-01 非常停止ボタン | 承認済み無負荷点検運転でベルトが動いていることをガード外から確認し、非常停止ボタンを押してください。ベルト、ブザー、画面を観察してください。 | ベルトコンベヤが停止し、ブザーが発報し、画面に非常停止状態が表示されること。3条件全てを満たすこと。 | 毎日の始業前 |
| SC-02 インターロック付きカバーG02 | SC-01の復帰確認後、無負荷点検運転中にガード外の所定位置からカバーを開いてください。内部へ手・身体を入れずベルトを観察してください。 | カバー開放により緊急停止し、ベルトコンベヤが停止すること。 | 毎日の始業前 |
| SC-03 開口部のエリアセンサーS03 | SC-02の復帰確認後、承認済み試験片・位置・方法で検出領域を遮り、ガード外からベルトを観察してください。身体で遮光して試験しないでください。 | 遮光を検出してベルトコンベヤが停止すること。センサー仕様と機械設計で承認された試験位置・停止確認条件を満たすこと。 | 毎日の始業前 |

SC-03はユーザー指定の動作確認を「遮光時に搬送を停止する」機能確認として記述した編集前提です。検出能力、応答時間、安全距離、停止時間、試験片と全検出領域の試験位置は設計検証で決定します。未検証の値や停止カテゴリ、PL/SILを保証しません。
SC-02の「緊急停止」はカバー開放による保護停止の記述で、非常停止ボタンと同一の回路・停止カテゴリであるという指定ではありません。

### 5.5.3 各項目の復帰と点検完了

1. ベルトの停止を確認してください。
2. 非常停止の解除、カバーの閉鎖、試験片の撤去を当該項目に応じて行ってください。
3. 解除・閉鎖・遮光解除だけではベルトが再始動しないことを確認してください。
4. 人員退避と安全状態を確認し、独立したリセットと運転開始操作で次の点検へ進んでください。
5. 全点検と再始動防止の結果を付録B.5へ記録してください。全て合格し、記録を確認した場合だけ通常運転を開始してください。

### 5.5.4 動作不具合を発見した場合

**動作不具合発見時は直ちに電源を切り、運転を禁止し、サービス窓口へ連絡してください。**

電源遮断は危険領域へ近づかず、ガード外の指定操作部から行ってください。非常停止だけを電源遮断の代用にしないでください。
停止しない、ブザーが鳴らない、表示されない、又は意図せず再始動する場合も不合格です。残る試験を続けないでください。
点検ID、現象、表示、型式・製造番号、発見日時と電源遮断の実施を記録し、サービス窓口へ伝えてください。
安全装置の無効化や自己判断による再投入をしないでください。サービス担当の是正と安全機能再確認が完了し、設備管理責任者が再開を承認するまで使用しないでください。

サービス窓口は前付「お問い合わせ先」を参照します。架空原稿では電話番号等が未設定のため、発行前に正式連絡先を記入します。未設定のまま実運用へ渡しません。


## 5.6 試運転・受入
試運転は安全機能の検証済み手順で段階的に行う想定です。無負荷運転、停止、非常停止、ガードの動作、リセットと再起動の分離、センサ動作、ダミーワークの搬送・排出を確認し、結果を記録します。**非常停止やインターロックの試験方法、合格停止時間、機能安全の達成性能は設計仕様書に基づいて確認するため本書で指示しません。**

不合格が一つでもある場合は通常運転へ引き渡さず、不適合処理と再検証を行います。
